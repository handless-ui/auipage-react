v0.1.0 已发布
  • 初始版本：发布 AuiRuntimeProvider、ChatContent、ThreadList 三套组件树。
  • 透出 @auipage/core 的 ChatTransportAdapter、MessageHistoryAdapter、ThreadListAdapter 与 generator。
  • defineTool 的 render 升级为 React 组件，支持带状态的交互式工具。
  • 组件不带样式，提供 aui-* class 与 data-* 属性作为样式钩子。
