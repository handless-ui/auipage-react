Concept 03组件 API

两套组件树加一个 Provider。所有组件都是透传风格：只挂约定的 class 与 data 属性，不内置样式和交互逻辑。

ChatContentThreadListrender-prop
01

AuiRuntimeProvider

App.tsx
<AuiRuntimeProvider adapter={adapter} tools={tools}>
    {/* 子树 */}
</AuiRuntimeProvider>
属性类型必填说明
adapter{ ChatTransport, MessageHistory, ThreadList }是三套适配器实例。
toolsReactTool[]否前端工具列表，详见 前端工具。
childrenReactNode否子树。

Provider 在 useRef 里装配，整个生命周期只创建一次；不同 Provider 实例各有独立 store 与 AuiPage，互不干扰。

02

ChatContent 组件树

tree
ChatContent.Root
├── ChatContent.Viewport           // 自动滚到底
│   └── ChatContent.Messages       // render-prop，按 message 渲染
│       └── ChatContent.Parts      // render-prop，按 part 渲染
└── ChatContent.Composer.Root      // form 容器，阻止默认提交
    ├── ChatContent.Composer.Input // 受控 textarea
    └── ChatContent.Composer.Send  // 发送按钮，执行中自动禁用
组件要点
Root纯透传 div，挂 aui-chat-content-root。
Viewport监听消息数量与全部片段文本总长度，只有内容溢出时才滚到底，不打断用户上滑。
Messageschildren 是 ({ message }) => node，每条消息调用一次。
Parts自动挂 data-role；children 为 ({ part }) => node，不传则走内置兜底（text/thinking 输出文本、tool-call 不显示）。
Composer.Input受控 textarea，值走 store 的 composerValue；Cmd/Ctrl + Enter 直接发送。
Composer.Sendbutton type="button"，执行中自动 disabled，缺省文案「发送」。

part 是判别联合类型，先按 type 收窄再取字段：

types.ts
type ChatContentPart =
    | { type: "text";     text: string }
    | { type: "loading";  text: string }
    | { type: "thinking"; text: string }
    | ToolCallPart;      // 见前端工具
03

ThreadList 组件树

tree
ThreadList.Root
├── ThreadList.New                   // 新建会话按钮
└── ThreadList.Items                  // render-prop，按 thread 渲染
    └── ThreadList.Item.Root         // 自动挂 data-status / data-active
        ├── ThreadList.Item.Trigger  // 切换会话（归档态不可激活）
        │   └── ThreadList.Item.Title
        ├── ThreadList.Item.Archive
        ├── ThreadList.Item.UnArchive
        └── ThreadList.Item.Delete
组件要点
New调 aui.newThread()，等价于 activeThread(undefined)。
Itemschildren 是 ({ thread }) => node。
Item.Root挂 data-status（regular / archived）与 data-active（出现即激活）。
Item.Trigger调 activeThread(threadId)；归档会话点不动，需先取消归档。
Item.Title渲染 thread.title，缺省回退「新会话」。
Archive / UnArchive / Delete分别调 archiveThread / unarchiveThread / deleteThread。
04

Hooks

main.tsx
import { useAuiContext, useMessageContext, useThreadListItem } from "@auipage/react";
Hook调用位置返回
useAuiContextProvider 子树内{ aui, store }
useMessageContextMessages 的 render-prop 子树{ message }
useThreadListItemItems 的 render-prop 子树{ thread }

三个 hook 在缺失上下文时都会抛错并给出修复提示，便于开发期定位。

05

样式钩子

组件不带 CSS，但每个节点都挂了稳定 class，可作为样式锚点：

节点class
ChatContent.Rootaui-chat-content-root
Viewport / Messages / Partsaui-chat-content-viewport / -messages / -parts
默认渲染的片段aui-chat-content-part + -{type}
Composer 三件aui-composer-root / -input / -send
ThreadList 树aui-thread-list-root / -new / -items
Item 系列aui-item-root / -trigger / -title / -archive / -unarchive / -delete

驱动样式的 data 属性：

节点属性取值
Partsdata-roleuser / assistant
Item.Rootdata-statusregular / archived
Item.Rootdata-active出现即表示当前激活
Composer.Senddata-disabled出现即表示执行中
