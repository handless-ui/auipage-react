headless · agent UI runtime

把对话界面
拆成状态和你的样式。

@auipage/react 是智能体页面的 Headless 组件库：它只给你消息流、会话列表、输入框的状态机与交互， 一个像素的样式都不带。适配器接你的后端，render-prop 接你的设计系统。

$ npm install @auipage/react

01

设计取向

Headless

状态归库，样式归你

组件只挂稳定的 aui-* class 与 data-* 属性，不带任何 CSS。 气泡、侧栏、输入区长什么样，由你的设计系统决定。

Adapter

后端无关

三套适配器 ChatTransport / MessageHistory / ThreadList 把 HTTP、SSE、WebSocket 全部挡在外面，换模型、换服务端只改适配器。

Composition

组合而非配置

没有几十个 props 的"智能组件"。消息用 render-prop 逐条渲染， 片段按 part.type 收窄，工具卡片就是你自己写的一个组件。

02

导出了什么

导出类型说明
AuiRuntimeProvider组件装配 AuiPage + zustand store，向下提供 context。
ChatContent组件树Root / Viewport / Messages / Parts + Composer 三件。
ThreadList组件树Root / New / Items / Item.*。
ChatTransportAdapter 等类三套适配器，从 @auipage/core 透出。
defineTool函数定义前端工具，render 是一个 React 组件。
generator工具函数把回调式流读取包成 AsyncGenerator。
03

真实组件跑在这里

LIVE WORKBENCHdist 产物 + 内存适配器 · 消息是逐字流式输出
这套界面用的是 dist/auipage-react.iife.js 与文档自己的 CSS： 组件没带样式，皮肤是文档写的 —— 换成你的设计系统只是另一份 CSS 的事。
04

最小骨架

App.tsx
import { AuiRuntimeProvider, ChatContent, ThreadList } from "@auipage/react";

function App() {
    return (
        <AuiRuntimeProvider adapter={adapter} tools={tools}>
            <ThreadList.Root>
                <ThreadList.New>新建会话</ThreadList.New>
                <ThreadList.Items>
                    {({ thread }) => (
                        <ThreadList.Item.Root>
                            <ThreadList.Item.Trigger>
                                <ThreadList.Item.Title>{thread.title}</ThreadList.Item.Title>
                            </ThreadList.Item.Trigger>
                        </ThreadList.Item.Root>
                    )}
                </ThreadList.Items>
            </ThreadList.Root>

            <ChatContent.Root>
                <ChatContent.Viewport>
                    <ChatContent.Messages>
                        {() => <ChatContent.Parts />}
                    </ChatContent.Messages>
                </ChatContent.Viewport>
                <ChatContent.Composer.Root>
                    <ChatContent.Composer.Input />
                    <ChatContent.Composer.Send>发送</ChatContent.Composer.Send>
                </ChatContent.Composer.Root>
            </ChatContent.Root>
        </AuiRuntimeProvider>
    );
}
