文档/指南/安装与接入

Guide 01安装与接入

先装包、再写三套适配器、最后挂 Provider —— 三步之后你就有了一套能用的对话界面骨架。

react 0.1.0React 18@auipage/core 0.1.0zustand 5
01

环境与依赖

组件基于 React 与 zustand，运行时由 @auipage/core 提供。装 @auipage/react 时会自动带上它们。

依赖版本作用
react / react-dom^18.3.1组件的宿主框架。React 19 目前没有 UMD 构建，用 CDN 直接引入时请锁 18。
@auipage/core^0.1.0编排器 AuiPage 与适配器基类、generator 都在这里。
zustand^5.0.14唯一的 React 侧状态源，组件用 selector 订阅。
TypeScript可选包里带 types/index.d.ts，无需额外装类型。
02

安装

terminal
npm install @auipage/react

组件库没有样式文件，不需要额外引入 CSS。

03

三步接入

第一步：写适配器。三个类实例按固定的 key 组装成一个对象，key 名由 core 约定。

adapter.ts
import {
    ChatTransportAdapter,
    MessageHistoryAdapter,
    ThreadListAdapter,
} from "@auipage/react";

const adapter = {
    ChatTransport: new ChatTransportAdapter({ /* run / response */ }),
    MessageHistory: new MessageHistoryAdapter({ /* load / append */ }),
    ThreadList: new ThreadListAdapter({ /* list / new / archive / ... */ }),
};

第二步：挂 Provider。它会创建 AuiPage 与 store， 并在挂载瞬间调用一次 adapter.ThreadList.list() 拉会话列表。

App.tsx
import { AuiRuntimeProvider } from "@auipage/react";

<AuiRuntimeProvider adapter={adapter} tools={tools}>
    {/* ChatContent / ThreadList */}
</AuiRuntimeProvider>

第三步：搭界面。组件树是命名空间结构，按层级组合即可， 样式通过 class 钩子接管。

每一步的细节分别见 适配器、组件 API、 前端工具、数据流与状态。

04

不打包，直接用 CDN

包里提供了 IIFE 构建，全局名是 AuipageReact，依赖外部全局 React：

index.html
<script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"><\/script>
<script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"><\/script>
<script src="https://unpkg.com/@auipage/react@latest/dist/auipage-react.iife.js"><\/script>

<script>
    const { AuiRuntimeProvider, ChatContent,
            ChatTransportAdapter, MessageHistoryAdapter,
            ThreadListAdapter } = AuipageReact;
<\/script>
顺序不能反。IIFE 构建在加载时就把 React 当参数接收， 所以 react 必须先于 auipage-react.iife.js 执行。
05

本地跑起来

仓库自带一个 playground 与 mock 服务：oipage-cli 同时起 mock（30000）与 vite（20000）， /api 走代理。

terminal
npm run dev
# http://localhost:20000/

mock 服务里预置了会话与历史消息，切换会话即可看到渲染效果； 发送消息会走 server/chat.js，默认接本地 ollama（qwen3.5）。
